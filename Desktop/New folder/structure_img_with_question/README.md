# Structure Image with Question

Structures Kaggle results into organized data and generates HTML reports.

## Files

| File | Purpose |
|------|---------|
| `generate_paper.py` | Generates individual question paper HTML pages. |
| `generate_report.py` | `build_html()` — reads `data/batch_manifest.json` and result JSONs, generates offline HTML report with image cards, type badges, and confidence scores. |
| `a.html` | Sample/scratch HTML template. |
| `question_paper.html` | Generated question paper output. |
| `question_report.html` | Main generated report (final output). |
| `question_template.html` | HTML template for individual question cards. |
| `data/` | Structured question data with per-image folders (auto-generated by pipeline). |

## Usage

```bash
python generate_report.py
```
